问题背景

很多网站在检测到浏览器插件（如油猴脚本）注入控制台时，会弹出警告：”检测到您的浏览器插件正在注入异常脚本，请使用隐身模式打开页面！”

这是因为网站通过监听 console 对象的方法调用或 error 事件来检测是否有脚本在”窥探”或修改控制台行为。

解决方案

  1. 拦截错误事件：阻止 error 和 unhandledrejection 事件的传播
  2. 伪装 console 方法：用空函数替换所有 console 方法，并伪装成原生函数

保存并启用脚本

测试效果

  1. 打开之前报错的网站
  2. 按 F12 打开开发者工具
  3. 切换到 Console（控制台）选项卡
  4. 错误页面不会再弹出”检测到插件注入”的警告

总结

脚本通过”静默”手段让网站无法检测到插件的存在，从而绕过”请使用隐身模式”的警告。它适用于绝大多数基于 console 检测的网站。
